GTi P4 v3 Flasher

for ESP32-P4 chip v3.x boards

Why a separate flasher?

The main GTi Flasher uses a flashing library that can't start up ("initialise") a P4 with chip v3.x yet. This page uses Espressif's newer library, which can. It writes the same firmware.

Loading the firmware details...
  1. Use Chrome or Edge on a computer.
  2. Plug the board in with a data USB-C cable, on the port you flash with.
  3. Close the Arduino serial monitor or anything else using that port.
  4. Press Install and pick the port. Don't unplug until it says done.

This browser has no Web Serial. Open this page in Chrome or Edge on a computer.
