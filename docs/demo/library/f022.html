Registered MegaBall V4.0

This is the official distibution of the MegaBall V4.0 ADF files from Ed and Al Mackey. MegaBall works with only a few emulators (the most recent releases of UAE do it nicely) due to some of its sound initialization routines -- ironicly put there to make MegaBall compatible with future Amiga hardware.

Unlike most Amiga ADFs you'll find MegaBall cannot be ran directly from the floppies. It's best that you make a directory on your hard drive somewhere where you have some space, and make a virtual hard drive to use it (in WinUAE, this is done on the "Hard Drives" panel, with the "Add Directory" button). Once you install Workbench on the hard drive, reboot the emulator from it. Then, insert the three floppies and use the installer on the first one to install MegaBall to the hard drive. For MegaBall to work, the sound emulation mode must be set to "Emulated, 100% accurate".
