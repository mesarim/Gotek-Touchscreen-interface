What this does

It asks the board's chip what it is (type and revision) over USB, then tells you which firmware to pick in the GTi Flasher. It only reads: nothing is written to the board. The board restarts normally when it's done.

This matters most for ESP32-P4 boards: chips of revision v1.x and v3.x need different firmware, and the boards look the same.

  1. Use Chrome or Edge on a computer (Web Serial is needed).
  2. Plug the board in with a data USB cable. On P4 boards use the port you flash with.
  3. Close the Arduino serial monitor or anything else using that port.
  4. Press Check my chip and pick the port.

This browser has no Web Serial. Open this page in Chrome or Edge on a computer.
