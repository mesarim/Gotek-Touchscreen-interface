# GTi CONFIG.TXT — Key Reference

_Auto-generated by the `gotek-docs` skill from the firmware source — the firmware is the source of truth. Do not hand-edit; regenerate after a build. Reference board: **Gotek_JC3248 `5.9.6-JC3248`**; the 4.3″ JC4827 shares the same key set. Regenerated 2026-09-09 after the `6=OMEGA` / `NL` template fix + the advanced-comment block._

Drop these lines into `CONFIG.TXT` at the root of the SD card (one `KEY=value` per line). Most also have an on-screen toggle — you rarely need to hand-edit. Keys are listed in the order the firmware's own template writes them.

| Key | Default | What it does |
|-----|---------|--------------|
| `THEME` | `0` | Theme: 0=NAVY 1=EMBER 2=MATRIX 3=PAPER 4=SYNTH 5=GOLD 6=OMEGA |
| `MODE` | `STANDALONE` | Transfer mode: STANDALONE (USB to Gotek) or WIRELESS (ESP-NOW to dongle) |
| `CAROUSEL` | `OFF` | CAROUSEL: default boot view. OFF=game list, ON=cover reel, LAST=restore last view. |
| `LOOP` | `0` | Loop cracktro splash: 1=loop until tapped, 0=auto-dismiss after 6s |
| `CRACKTRO` | `0` | Boot cracktro style: 0=random each boot, or pick one: 1=COPPER CLASSIC  2=STARFIELD  3=RAINBOW RASTER 4=PLASMA  5=BOING BALL  6=SYNTHWAVE  7=OMEGAWARE |
| `FONT` | `NORMAL` | Font size: SMALL, NORMAL, LARGE |
| `LANG` | `EN` | Language: EN, FR, IT, ES, DE, NL  (pull the SD and edit this line if you get stuck) |
| `ROTATE` | `0` | Screen rotation in degrees: 0 or 180 = landscape, 90 or 270 = portrait. |
| `COVERMIN` | `140` | COVERMIN: hide covers whose short side is under N px (0 = show all) - keeps the reel + panel clean. |
| `REELFILTER` | `OFF` | REELFILTER: ON = the reel (cover carousel) shows only games whose cover passes COVERMIN; the A-Z list still shows every game. OFF = reel shows all games. |
| `COMPACT` | `OFF` | COMPACT: OFF = cover art + list, ON = maximise the game list (cover collapses to a strip) |
| `BTNSTYLE` | `PILL` | BTNSTYLE: reel button style. PILL=rounded coloured buttons (default), FLAT=flat bar. |
| `CAP` | `32` | CAP: max wireless dongles the scan will list (default 32, up to 64) |
| `HIVEMIND` | `ON` | HIVEMIND: wireless FLING fan-out. ON=all paired MuCa dongles (classic), OFF=selected dongle only. |
| `TAPLOAD` | `OFF` | TAPLOAD: ON = tapping the already-highlighted game row loads it (old double-tap) |
| `HOTSWAP` | `OFF` | HOTSWAP: ON = tapping another disk while loaded swaps to it instantly |
| `FORCESWAP` | `OFF` | FORCESWAP: ON = swap disk contents without the USB eject/re-attach cycle |
| `SAVES` | `COPY` | SAVES: save-game persistence. OFF = classic (lost on eject), COPY = kept as GameName.sav.adf beside the master, OVERWRITE = patch the master. |
| `SDSPEED` | `20` | SDSPEED: SD card clock. 20 = safe default, 40 = ~1.7x faster reads if your card holds it (auto-falls back to 20). |
| `CATEGORIES` | `OFF` | CATEGORIES: OFF = flat library. ON = browse by category (a top-level folder with no disk images, only subfolders, is a category). |
| `NESTING` | `OFF` | NESTING: OFF = one category level. ON = allow sub-categories (folders within category folders). |
| `SCREENSAVER` | `ON` | SCREENSAVER: idle slideshow. ON = show it after a few minutes idle, OFF = never. |
| `SSMODE` | `SLIDES` | SSMODE: SLIDES = full-screen photo slideshow (default), BOUNCE = bouncing logo, MATRIX = code rain. |
| `SSFX` | `SHUFFLE` | SSFX: transition between slides - SHUFFLE (random), FADE, DISSOLVE, SLIDE, or CUT. |
| `SSTIME` | `6` | SSTIME: seconds each slide is shown (2-120). |
| `SSFAV` | `ON` | SSFAV: ON = also slideshow favourited game covers; OFF = only /screensaver/ images. |
| `LINK` | `ESPNOW` | LINK: dongle transport. ESPNOW = the dongle's own AP + ESP-NOW (default). HOMEWIFI = route the FLING via your home router to a Webby dongle's gotek.local. |
| `HOME_SSID` | `—` | HOME_SSID: your home WiFi name (only used when LINK=HOMEWIFI). |
| `HOME_PASS` | `—` | HOME_PASS: your home WiFi password (only used when LINK=HOMEWIFI). |
| `DONGLE_HOME_IP` | `—` | DONGLE_HOME_IP: auto-filled cache of the dongle's home-network IP (mDNS gotek.local is the primary lookup). |

## Read by the firmware, not yet an active template key

These keys the firmware **honours** but its self-documenting `CONFIG.TXT` template doesn't write as an active `KEY=` line (so a fresh card doesn't switch them on for you). They work today — add the line yourself. Behaviour below is read straight from the parser. `WEBUI` and `LOG` are now surfaced as **commented hints** in the fresh-card template's "Advanced" block, so upgraders can discover them without the template turning them on.

| Key | Default | What it does |
|-----|---------|--------------|
| `WEBUI` | `OFF` | `ON` = serve the shared web panel over home WiFi (needs `HOME_SSID`/`HOME_PASS` + `LINK=HOMEWIFI`). **Now a commented hint in the template.** |
| `LOG` | `ON` | `OFF` = disable the `/gti.log` diagnostic log (on by default). **Now a commented hint in the template.** |
| `DAV / DAV_ENABLED` | `OFF` | Enable the WebDAV client. `DAV_ENABLED` is the same switch under the OMEGAWARE-tree name. |
| `DAV_HOST` | `—` | WebDAV server hostname or IP. |
| `DAV_PORT` | `443` | WebDAV port (1–65535; anything invalid falls back to 443). |
| `DAV_HTTPS` | `ON` | `ON` = TLS (default), `OFF` = plain HTTP. |
| `DAV_USER` | `—` | WebDAV Basic-Auth username. |
| `DAV_PASS` | `—` | WebDAV Basic-Auth password. |
| `DAV_PATH` | `/` | Base path on the WebDAV server. |
| `DAV_TEST` | `—` | Smoke test — fetch this one remote path once at boot to prove the wiring. |
| `SS_IDLE` | `—` | Seconds of idle before the screensaver starts (overrides the built-in default). Fine-tuning; intentionally kept out of the template. |
| `SS_LOAD` | `—` | Seconds the load screen lingers before the screensaver may take over. Fine-tuning; intentionally kept out of the template. |
| `WIFI_CLIENT_SSID` | `—` | Alias of `HOME_SSID` (OMEGAWARE-tree name; empty never erases a value set by the other key). |
| `WIFI_CLIENT_PASS` | `—` | Alias of `HOME_PASS` (OMEGAWARE-tree name). |

## Template text drift — RESOLVED in this build

Both drift items the skill flagged on the previous build are now fixed in the firmware template (fresh-card `generateDefaultConfig` **and** the upgrader `selfHealConfig`):

- **`THEME`** — template now lists `0=NAVY 1=EMBER 2=MATRIX 3=PAPER 4=SYNTH 5=GOLD 6=OMEGA`. OMEGA (theme 6, the house reskin) already shipped and was already selectable from the INFO screen; it's now named in the config.
- **`LANG`** — template now lists `EN, FR, IT, ES, DE, NL`. Dutch already shipped; it's now named in the config.

An **Advanced (commented)** block was also added to the fresh-card template documenting the two useful opt-in toggles (`WEBUI`, `LOG`) as `#` hints — discoverable without adding active lines to every user's config.

_Themes present in `5.9.6-JC3248`: NAVY, EMBER, MATRIX, PAPER, SYNTH, GOLD, OMEGA._
_Languages present: EN, FR, IT, ES, DE, NL._
