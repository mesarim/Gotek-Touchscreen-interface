Board not showing up when you flash?

If nothing appears in the serial-port picker, your board is likely using a CH340 / CH341 USB-serial chip and the driver isn't loaded — so no port exists yet. Install it once, replug, and try again:

Windows: CH341SER driver · macOS: CH34xSER_MAC (often already built in).

How to use the GTi
You've flashed a board — here's the path from an empty SD card to a full library, plus every setting worth knowing.

1 · Get your SD card ready

Format a microSD as FAT32 and make an /ADF folder for Amiga disk images (add /DSK for Atari ST / PC .dsk if you use them). Drop a folder per game, or loose images — the GTi reads both.

/ (SD root) ├─ ADF/ │ ├─ Turrican/ │ │ ├─ Turrican.adf ← the disk image │ │ ├─ Turrican.jpg ← cover art (same name) │ │ ├─ Turrican.nfo ← Title: / Blurb: (optional) │ │ └─ Turrican.rtfm ← how-to-play text (optional) │ └─ Bard's Tale/ │ ├─ BardsTale-1.adf ← multi-disk: -1, -2, -3… │ ├─ BardsTale-2.adf │ └─ BardsTale.jpg ├─ DSK/ ← Atari ST / PC .dsk, .img… ├─ GENERIC/ ← GEN mode: mount any file format ├─ screensaver/ ← drop .jpg here for a slideshow └─ CONFIG.TXT ← all your settings (see §7)
Multi-disk games: name the images Name-1.adf, Name-2.adf… and the GTi collapses them into one entry with a disk stepper.

2 · Cover art & game info

Name the cover to match the game — Turrican.jpg beside Turrican.adf. JPG is best (it decodes fast and downscales on the fly); PNG works but keep it under ~1400 px or it can run the panel out of memory. Two optional sidecars: a .nfo with Title: and Blurb: lines fills the info panel, and a .rtfm text file becomes an in-device manual.

Clean covers: COVERMIN hides tiny low-res art, and REELFILTER keeps the cover reel to good art only while the A-Z list still shows every game. Both are CONFIG.TXT switches.

3 · First boot

Insert the SD and power up. The first boot builds a one-off cover-thumbnail cache — let it finish. Every boot after that is instant, and USB floppy emulation runs underneath the whole time.

Use an A1/A2 card. Random-read speed is everything here — a rated card scans roughly 300 games/sec vs ~9/sec on a cheap one. It's the single biggest difference for a large library.

4 · Day to day — the controls

Two ways to browse: LIST (A-Z with a jump rail) or REEL (spinning cover flow). Tap a game, then INSERT to load it into the drive; EJECT to pull it back out.

LIST / REEL
Switch between the A-Z list and the cover carousel.
SEARCH
The magnifier — type to filter the whole library live.
A-Z rail
Jump to a letter; only letters you actually own show up.
★ Favourite
Star a game. The reel's source cycles ALL → FAV → MOST (most-played).
ROLL
The dice — spin to a random game within the current source.
INFO
Cover, blurb, disk details, and the settings / maintenance actions.
THEME
Cycle the six palettes: Navy, Ember, Matrix, Paper, Synth, Gold.

5 · Add games without opening the case

From the INFO tab: SD ACCESS mounts the card as a USB drive over the data cable, so you copy games and covers straight on — no card removal. FW UPDATE applies a firmware .bin left at the SD root (the SD-access path in this flasher). RESCAN SD rebuilds the library after you've added files.

6 · Go wireless

With a paired dongle you can load disks over the air — from a GTi panel (Scan Dongles → Select), from the dongle's own GotekOMEGA web page, or the GTi phone app.

7 · Settings — CONFIG.TXT

Everything is tunable from a plain CONFIG.TXT at the SD root — pull the card, edit a line, done. New keys self-heal in on a firmware update, so you never lose your settings. The ones worth knowing:

THEME
0–5 · Navy / Ember / Matrix / Paper / Synth / Gold.
FONT
SMALL / LARGE / BIG — text scale, low-vision friendly.
LANG
EN / FR / IT / ES / DE.
ROTATE
0 / 90 / 180 / 270 — screen orientation.
CAROUSEL
OFF / ON / LAST — default boot view (list, reel, or last used).
COMPACT
ON maximises the list; the cover collapses to a strip.
COVERMIN
Hide covers whose short side is under N px (0 = show all).
REELFILTER
ON = reel shows only good covers; the list is untouched.
CATEGORIES
ON = browse by folder buckets (Games / Apps / OS…).
SCREENSAVER
ON / OFF · SSMODE = BOUNCE / SLIDES / MATRIX.
SAVES
Save-game write-back to the SD card.
Most features ship OFF by default — your GTi stays exactly as it is until you turn one on.
Load over WiFi — nothing to flash
If you already have a flashed dongle, you don't need this flasher at all. Load disks like this:

From your phone — the dongle's own web page

The dongle makes its own WiFi network, GotekOMEGA. Join it, open the page, drag an .adf onto it, and it's in the drive. No SD card, no app, no cloud.

Join GotekOMEGA → open 192.168.4.1 → drop a disk

From the GTi mobile app

Scan for dongles on your network, tap one, push a disk. Handy when several dongles share the house WiFi.

Open app → Scan → pick your dongle → load

From a GTi touchscreen

Any flashed panel can pair with a dongle and fling disks to it wirelessly — Scan Dongles → Select → load. That's the whole point of the wireless side.

What is the GTi?
A touchscreen front-end for the Gotek floppy emulator. In 60 seconds:
Where it came from

A Gotek deserves better than three seven-segment digits

The Gotek replaces an Amiga's (or Atari's, PC's, synth's) floppy drive with a USB stick full of disk images — but you pick them by a tiny number readout. The GTi bolts a proper touchscreen on the front: see your games, tap to load.

Where it is now

Cover art, categories, saves, and wireless

A full library browser with cover art, six themes, a spinning carousel, type-to-search, and save-game write-back to the SD card. Multiple screen sizes from 2.8″ to 7″, plus wireless dongles so the disk lives on a tiny board in the Gotek and the screen drives it over the air.

Where it's going

The P4 flagship, bigger panels, and the web

A new ESP32-P4 board (the 4.3″ 480×800 flagship) that self-updates its own WiFi co-processor from the SD card; 7-inch panels; a browser + phone-app path for people who never want to flash anything; and a fleet mode to drive several dongles at once.

Same flasher engine under the hood — esp-web-tools over Web Serial, Chrome / Edge on desktop.
