WiFi Access Point

Direct connection hotspot — always active for setup

15 dBm

Higher means the router hears the device better, which is what improves transfer speed — at the cost of peak current, so lower it if the device is powered from an old machine's USB port and misbehaves. This does not change the signal strengths shown when scanning: those are how well this device hears each network, which is a property of its receiver. Takes effect after a reboot.

Reachable as gotek.local. Give every Gotek its own name (gotek1, gotek2, ...) — two devices with the same name fight over it and only one wins.

Panel Options

Saved to CONFIG.TXT on the card. Most of these apply at the next boot — use the Reboot button below after saving.

SD Card Access

Reboots the device into card-reader mode: the SD card appears as a USB drive on whatever computer the device is plugged into — manage the library without pulling the card. You can unplug and move the cable to a computer after pressing this; the mode survives the power loss. Tap the device's screen to return to normal operation.

Firmware

Update over WiFi, no cable. The image is written to the spare slot and the device restarts into it; if anything goes wrong it keeps running what it is running now.
